# Pruebas iniciales

1. Confirmar que el equipo responde en la red local.
2. Confirmar que el puerto SDK es `8000`.
3. Ejecutar login correcto desde la terminal.
4. Probar contraseña incorrecta y registrar solo el codigo de error.
5. Probar IP inaccesible.
6. Confirmar que siempre aparecen logout y cleanup en una ejecución exitosa.
7. Revisar que ningun log o respuesta contiene la contraseña.

La compatibilidad de HTTPS, ISAPI, alarmas, registros y video se validara en fases posteriores con el modelo y firmware reales.
